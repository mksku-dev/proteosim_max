# Proteosim Course Package (Max)


## Functionality:

### Protein Digestion 
- Loading and reading FASTA files 
- Converting FASTA into a dictonary 
- Digestion of Proteins

### Liquid Chromatography
- Calculation of retention time of peptide sequences 
- Visualization of retention times via histogram

### Mass Spectra Simulation
- Calculation of m/z values
- Fragmentation of peptid sequences and calculating the m/z values 
- Generating random intensity values for MS spectra 
- Visaulization of MS via bar plot

## Requirements/ Installation steps: 
- numpy
- pandas
- matplotlib
- pyteomics
